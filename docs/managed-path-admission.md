# Managed independent affine path and IS admission

The dedicated `affine-path-production-chunk` adapter consumes an actual settled
`affine-path-qualification` train/validation pilot. Generic affine adapters keep
their existing formal refusal; an operator report or analytical/Gaussian pass
cannot replace the own-path source pointer.

`PathProductionPolicy` separately freezes the complete target request, model,
current code, full source request and qualification-policy hashes, and job cap
(at most 7200 seconds). Source and target retain the same physical initial law,
horizon, finite grid, functional/region, model and original cumulative arm.
Only request ID, seed, coupling ID, sample count, chunk size and tolerance may
differ. Both seed and coupling ID, and the request ID, must differ. This proves
distinct declared sampling identities, not a statistical independence theorem
for a finite PRNG. The unchanged source accuracy cap must fit target tolerance.
The proposal and thresholds remain source-frozen; no held-out tuning or rescue.

Before protected target input reads, the current owner checks unique frozen
policies and observed-error metric, complete source/request/method/original-arm
and code/root bindings, live consumer evaluation permission, source registry,
command, pilot admission, train/validation split, immutable actual output and
its sufficient statistics, every saved numeric check and unknown component.
Source native RESERVE/WORKER_STARTED/TREE_STOPPED/SETTLE/completion must exist in
order with positive native cost under its frozen pilot cap. Saved certificates
are bounded and method-specific, including reversible physical four plus four
auxiliaries; arithmetic on them does not re-run a sampler, exponential or CDF.

The target actually samples its own frozen stream and captures its own detached
final sufficient statistics. Partial checkpoints continue through the existing
shared recovery protocol; counters/RNG/method/proposal identity prevent repeated
samples. A completed checkpoint can finalize from its saved statistics using
the existing sampler's no-more-paths branch. No new ledger or stop protocol is
created. All target attempts/resumes/retries retain the original arm's charges.

The reference law is exactly the source's same declared physical/functional
law, not its random estimate. The target does not re-run the hard-bounded
dyadic reference producer. The original sampler still computes its existing
float64 analytic/time-bias diagnostics; these are not certificates and their
actual time remains charged. It reserves its full kernel work proxy and bounded 64 MiB
saved-proof pools; physical resource dimension stays four. Source reference
operation counts are labeled settled-source-only; actual target time is still
natively charged under its separately frozen cap.

`path_output_analysis` binds the complete original kernel output, original
error budget, target statistics and owner evidence. Reference width, signed
time bias, actual realized scalar distances, estimated sampling uncertainty,
weighted ESS and unknown implementation/model errors stay separate. The
adapter replaces only reference/time components with saved bounded meanings;
the owner reconstitutes and checks the original full functional hash.

Input admission and numerical outcome are distinct. The outer result's
`qualification=qualified` is the current formal input-admission receipt, and
`status=SUCCEEDED` means the native computation completed. Neither means that
this independent realization passed its numeric thresholds. The explicit
`forecast.current_output_qualification` and `path_output_analysis.status` are
`PASSED` or `FAILED` from the target's own checks. No-hit/low-ESS/degenerate IS,
MC uncertainty or realized-error failure stays a complete charged artifact and
matrix row, with its actual estimator status and diagnostics. It must not be
counted as numerically qualified or promoted from the source's pass. The owner
validates both honest outcomes; it refuses fabricated values or classification.

Intervals remain estimated-only (ideal-iid binomial formula for ordinary zero/
all-hit MC, weighted normal/ESS diagnostics for IS). No float64/PRNG coverage,
sampler-roundoff, global distribution, nonlinear-model or scientific-study
approval is implied; `scientific_qualification` stays false. The independent
paper saved-proof reader checks the settled source, same physical law, saved
statistics and current classification independently, without runtime imports
or numerical-engine replay. Its no-fallback CLI reports PASSED and FAILED
counts separately. Completed numeric failures/unresolved outputs do not enter
complete paired aggregation or adjudication; execution status, metrics, costs,
expected-cell denominators and CSV numeric dispositions are preserved.
Runtime evidence import reconstructs both `comparison_eligible_cells` and
`path_output_dispositions` columns exactly as the paired Paper serializer does,
including empty-metric rows and managed comparison proof fields. Whole-table
byte equality and the original manifest/index/worker-proof checks remain
mandatory: resealing CSV/index/manifest hashes cannot change these columns.
Legacy aggregates without eligibility fields retain their old table shape;
partial or mixed new field sets are refused, never interpreted as legacy or
filled with fabricated zero counts. This serialization does not itself certify
the numerical classification or grant scientific qualification.
Disposable engineering controls exercise all four path families through actual
supervised formal 80% save/ACK, native tree stop, reopened linked restoration,
exact current final statistics and functional identity, original-arm costs,
authorized export, and the independent saved-proof reader/CLI. Completed-state
controls also refuse any new paths, unused analytic metric or bounded-reference
producer replay. These checks use one fixed affine law and coarse frozen
tolerances; they are not complete method or physical-axis qualification,
independent research blocks, a scientific study, or paper delivery. Those full
qualification and delivery steps remain required. The CI job wrapper allows
45 minutes for dependency installation and the complete mandatory test suite;
this does not change any worker deadline or original cumulative research arm.
Disposable unit-test stores/grants are not the official shared research root.
