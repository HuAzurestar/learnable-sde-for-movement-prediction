# Managed affine MLMC pilot and independent production admission

The explicit `affine-mlmc-production-chunk`1.0.0 adapter consumes a separately
registered `MLMCProductionPolicy` and an actual successful, settled
`affine-mlmc-qualification-chunk` pilot. It does not run because a pilot proposed
an allocation, because an operator pass flag exists, or because another method
has analytic qualification. All execution still uses the shared owner/ledger.

Before held-out input, the owner verifies the full model/source/request/grid,
both original pilot policies, target policy and preregistration/primary metric,
actual source admission/result/artifact, explicit source consumer grant, original
cumulative MLMC arm, measured native-stop settlement and completion event order.
The pilot must have consumed train/validation, not held-out input. Saved rational
enclosures and moments are checked with bounded arithmetic; matrix exponentials
and CDF references are not rerun in free owner preflight.

Production uses the pilot's registered independent seed/coupling root in phase1,
not its phase2 pilot stream. Level count/grid are unchanged and the complete
allocation must equal the actual bounded pilot proposal. Allocation, all hashes
and job cap<=7200s are frozen in a separate preregistration before target input.
Existing total work/sample caps and the same original arm remain authoritative;
changing horizon, seed, study, retry or resume does not create new budget. The
new adapter reserves conservative64MiB saved-evidence pools without changing the
physical4-state SI law. No grants, ledger, allocation execution or retry are
automatically created.

The current actual production scalar/level moments/SE/interval are rechecked by
the worker and owner. Qualified output needs finite, positive observed level
variances and SE within the already frozen sampling tolerance. Source readiness
alone cannot bless a failed or unresolved current production estimate. Model
error and sampler roundoff remain NOT_IDENTIFIABLE; normal intervals remain
ESTIMATED and are not a rigorous finite-sample coverage certificate. Signed
probability estimates/intervals are never clipped. The continuous/finest-grid
reference width and signed time-bias enclosure are BOUNDED; current scalar error
upper versus the declared continuous law includes sampling/implementation, not
a fake separation or deterministic roundoff bound.

Actual source and production evidence is exported only under independently
checked disclosure permissions. The paired paper reader uses stdlib and saved
bounded certificates, rederives statistics/allocation/bias and source/cost/
resource/current-output bindings. Its admission-only CLI requires a separately
trusted authorized bundle hash. It does not weaken full comparison candidate
requirements, adjudicate statistics, qualify a fitted model, prove authenticity
of an arbitrary self-rehashed journal or establish an MLMC complexity theorem.

Chunk recovery uses existing owner save/ACK, hash-bound completed statistics,
independent phase1 stream and same-arm charge. Actual formal-production-specific
interrupted/reopened-resume validation remains required; existing unqualified
MLMC restore checks are not claimed as that proof. Coverage/stability research,
other methods, all axes, actual oracle/synthetic-or-qualified-model studies,
manuscript, verification/review/acceptance and merged delivery remain required.

Engineering controls use disposable synthetic stores and explicit test grants,
not official research evidence or authority. Actual study execution still needs
the operator's existing shared runtime/store and approved frozen permissions.
