# Managed affine cubature admission

The restart-only `affine-cubature` target has a dedicated admission path from
an actual settled `affine-cubature-qualification` pilot. Qualification is for
one frozen affine request and endpoint functional, not observed-model validity,
nonlinear Gaussian closure, an entire method family or a completed study.
No store, data permission, budget arm or research run is created by this API.
The ordinary adapter is version1.1.0; its numerical qualifier remains1.0.0.
The new source hash prevents old-source pilots from qualifying changed code.

## Source pointer and frozen policy

The execution package's payload contains `managed_cubature_qualification` with
exactly `schema_version`, `policy`, `source_attempt_id`, `source_artifact_id`,
`source_authorization_id` and `source_authorization_version`. The schema is
`managed-affine-cubature-qualification-v1`; the policy is the complete
`CubatureQualificationPolicy` manifest. The preregistration lists that policy
exactly once in `cubature_qualification_policies`, with primary metric
`absolute_error_upper_vs_declared_affine_law` in meters or unit1.

Generic package contract checks and blind preregistration are necessary but
insufficient. A numerical qualifier remains pilot/train-validation only.
Neither a caller pass flag nor an analytic qualification pointer substitutes
for this method's actual source worker and cost evidence.

## Pre-read owner checks

Before the held-out protocol read, the owner validates actual completed source
artifact/reuse, same code/root/store/arm/model/request/policy, source consumer
permission, pilot split, and unique reservation/admission/worker/native-stop/
settlement/completion ordering. Source cost is positive, measured and bounded
by its frozen reservation and pilot cap. Both runs retain the original sole
cumulative cubature arm; failed attempts or new studies do not reset it.

The owner recomputes bounded arithmetic over saved continuous and Euler
certificates: reference width, actual scalar implementation error, signed time
bias, state-scaled transition growth and reference operation counts. Eight
equal-weight points, no covariance projection and both output/replay work
counts are mandatory. No exponential, matrix/CDF certificate or pilot replay
runs in preflight. The source result is at most512KiB, owner evidence2MiB.

## Affine-only closure and current output

For a four-dimensional Gaussian input with covariance `P = R R^T`, the eight
points `mean +/- 2 R[:,i]`, each weighted1/8, have precisely that mathematical
mean and covariance. An affine Euler map sends these to the same mean and
covariance as the Gaussian Euler recurrence; adding Gaussian diffusion preserves
Gaussianity. Thus mathematical finite-grid closure error is zero for the
declared affine Gaussian law. Floating cubature arithmetic is not thereby exact:
the actual scalar is checked against independent saved Euler intervals, and
time bias is checked separately against continuous-law intervals.

The formal worker keeps its own `gaussian-cubature-euler-v1` identity, zero
sampling count, strict PSD refusal and `APPROXIMATION_ONLY` estimator status.
It checks its current scalar rather than copying the pilot's bound, and does
not compute/discard a new float64 reference. Only admitted affine finite-grid
closure is marked identified zero; model error remains unknown. Unqualified
ordinary/pilot outputs retain their original unknown error fields.

## Independent export verification

The authorized export includes source owner receipts and actual target bytes.
The separate Paper CLI is `python scripts/pirc25/validate_cubature.py bundle.json
--expected-hash <separately-trusted-authorized-bundle-hash>`. Its stdlib reader
checks policy, saved arithmetic, source settlement before target exposure,
consumer/export permission, current scalar and separated errors with bounded
structural/rational quotas. Missing or substituted proof cannot fall through
generic/analytic admission. Failed/missing rows retain their denominator.

Hashes do not authenticate arbitrary self-rehashed journals. This verifies
recorded request-level admission under a trusted owner/export boundary, not
statistical adjudication, independent DSDE sampling or scientific model approval.
The actual pilot/formal/reuse/export/independent-reader integration tests use
disposable synthetic engineering fixtures, not official research authority.
