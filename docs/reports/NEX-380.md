# NEX-380 OSM distance-field evidence

## Outcome

Two real-PBF interior smoke ranges produced all three channels at 50 m. These
are deliberately partial coverage artifacts, not claims of whole-GB or
whole-Zhejiang coverage. Every other country and every point outside the two
coverage masks remains unavailable (`has_osm=0`, distance NaN).

## Real condition-slice smoke

Existing validation slice
`10177005_Freestyle_2023_09_13_17_10_03_cond.parquet` contains 4,821 points.
The non-mutating adapter produced:

- 2,345 covered points with all three distances finite;
- 2,476 uncovered points with `has_osm=0` and all three distances NaN;
- exact equality of the pre-existing `dem_elev`, `dem_slope`, `landcover`, and
  `has_map` columns;
- output SHA-256 `62df689bcde0d679c49cc504d71460aef1c98f5d85ce56b359b651d3ad3a997f`.

The initial direct script invocation exposed two adapter defects (repository
module path and masked `uint8` NaN conversion). Both failed before output was
written, were fixed, and are covered by tests.

## Failure and degradation ledger

1. Initial environment had no osmium/GDAL CLI. A repository-local Python
   fallback (`osmium 4.3.1`, pyproj 3.7.1, rasterio 1.4.4, SciPy 1.15.3,
   Shapely 2.1.2) completed Zhejiang. osmium-tool 1.19.1 was later installed in
   a repository-local ignored directory for GB prefiltering.
2. GB `complete_ways` extract was valid, but Python geometry scanning exceeded
   the ten-minute smoke gate. It was terminated with no manifest/output claim.
3. The successful GB degradation uses a smaller `simple` extract whose bbox
   margin exceeds the 2 km cap. This is acceptable for the declared interior
   smoke only, not for country-wide production.
4. Full GB, full Zhejiang, relation-only multipolygons, and all other countries
   remain uncovered. Downstream experiments must retain the existing honest
   three-terrain-channel baseline outside these masks.
