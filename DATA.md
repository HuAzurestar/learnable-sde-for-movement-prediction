# Data contract and release boundary

This repository intentionally contains no research dataset, trajectory sample,
derived per-segment prediction, or trained checkpoint. Tests and examples use
deterministic synthetic data generated by `application/synthetic.py`.

## Local configuration

Set `LEARNABLE_SDE_DATA_ROOT` to a directory containing the trajectory tables.
If it is unset, the loader resolves `.local/data` below the repository root.
Both locations are ignored by Git.

The trajectory loader currently expects:

- `unified_full_leg.parquet`: the main table;
- `smoke_fullleg.parquet`: an optional local smoke subset;
- `global_splits.json`: file-level train/validation/evaluation assignments;
- `zhejiang_holdout.parquet` and `zhejiang_splits.json`: optional regional
  holdout files retained for compatibility with the research protocol.

Required table fields are `segment_id`, `file_id`, `t`, `x`, and `y`. Time must
be strictly increasing within a segment, state values must be finite, and every
segment must contain at least two observations. Validation failures raise
`DataValidationError`; invalid rows are not silently discarded.

## Public-release rule

Do not commit any of the following:

- raw or transformed trajectories;
- latitude, longitude, timestamps, file identifiers, or segment identifiers;
- per-sample forecasts or row-level evaluation dumps;
- model checkpoints trained on non-public data;
- archives that contain any excluded item.

Only aggregate metrics may be considered for a later public results release.
They require a separate license and privacy review before publication.
